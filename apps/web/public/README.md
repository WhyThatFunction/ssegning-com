# apps/web/public

Static assets served from the site root.

Kept in git deliberately, even while empty apart from this file: `apps/web/Dockerfile`
does `COPY --from=builder /app/apps/web/public ./apps/web/public`, and git does not
track empty directories. Without a tracked file in here that COPY fails in any clean
checkout — which is every CI build — with:

    failed to compute cache key: "/app/apps/web/public": not found

A local build does not reproduce it, because the untracked empty directory is sitting
on disk. Do not delete this file unless real assets are added alongside it.

Note that `robots.txt`, `sitemap.xml` and the Open Graph image are NOT here — they are
generated by route handlers in `src/app/` (`robots.ts`, `sitemap.ts`,
`opengraph-image.tsx`) so they can read live CMS content.
